Base URL

http://localhost:8080/api

Data Endpoints

GET /api/people/firstnames

Description: Returns a list of all person IDs with their first names.

Response Example:

{
  "data": [
    {"id": 1, "firstName": "John"},
    {"id": 2, "firstName": "Mary"},
    ...
  ],
  "total": 2000
}
⚠️ Potential Issues: This endpoint may return random HTTP errors (500, 503, 504). Implement retry logic with exponential backoff.

GET /api/people/surnames

Description: Returns a list of all person IDs with their surnames.

Response Example:

{
  "data": [
    {"id": 1, "surname": "Smith"},
    {"id": 2, "surname": "Johnson"},
    ...
  ],
  "total": 2000
}
⚠️ Potential Issues: This endpoint has rate limiting. You may receive 429 (Too Many Requests) responses with a Retry-After header. Respect the rate limits and implement proper throttling.

GET /api/people/ages?cursor={cursor}

Description: Returns a paginated list of person IDs with their ages.

Query Parameters:

  • cursor (optional): Pagination cursor. Start with no cursor or cursor=0

Response Example:

{
  "data": [
    {"id": 1, "age": 25},
    {"id": 2, "age": 30},
    ...
  ],
  "cursor": "50",
  "hasMore": true,
  "total": 2000
}
⚠️ Potential Issues: This endpoint requires cursor-based pagination. Use the returned cursor value to fetch the next page. Continue until hasMore is false.

Submission Endpoints

POST /api/submit

Description: Submit your CSV solution for validation.

Request Body (form-data):

  • participantName (string, required): Your name or identifier
  • csvContent (string, required): Your complete CSV content

Response Example (Success):

{
  "success": true,
  "message": "Perfect! All 2000 records are correct!",
  "submission": {
    "participantName": "John Doe",
    "submittedAt": "2025-11-03T10:30:00",
    "isCorrect": true,
    "totalRecords": 2000,
    "correctRecords": 2000
  },
  "successRate": 1.0,
  "redirectToMeme": false
}

Response Example (Failure):

{
  "success": false,
  "message": "Validation failed. 1700 out of 2000 records are correct...",
  "submission": {...},
  "successRate": 0.85,
  "redirectToMeme": false
}
🚨 Less than 10% correct? If your success rate is below 10%, you'll be redirected to a special page. Try again!

POST /api/submit/file

Description: Submit your CSV file via file upload.

Request Body (multipart/form-data):

  • participantName (string, required): Your name or identifier
  • file (file, required): Your CSV file

Expected CSV Format

Your CSV file must have exactly 2000 rows (plus header) with this format:

firstName,surname,age,computedValue
John,Smith,25,John25Smith
Mary,Johnson,30,Mary30Johnson
...

Validation Rules

  • Header row must include: firstName, surname, age, computedValue
  • Exactly 2000 data rows required
  • All person data must match the API data exactly
  • Computed value must be: firstName + age + surname (concatenated as string)
  • No duplicate people
  • All 2000 people from the API must be included

Error Handling Best Practices

1. Retry Logic with Exponential Backoff

async function fetchWithRetry(url, maxRetries = 5) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      const response = await fetch(url);
      if (response.ok) return response;
      if (response.status >= 500) {
        await sleep(Math.pow(2, i) * 1000);
        continue;
      }
      throw new Error(\`HTTP \${response.status}\`);
    } catch (error) {
      if (i === maxRetries - 1) throw error;
      await sleep(Math.pow(2, i) * 1000);
    }
  }
}

2. Rate Limit Handling

if (response.status === 429) {
  const retryAfter = response.headers.get('Retry-After');
  await sleep((parseInt(retryAfter) || 60) * 1000);
  // Retry the request
}

3. Pagination Loop

let cursor = null;
let allData = [];
do {
  const url = cursor 
    ? \`/api/people/ages?cursor=\${cursor}\`
    : '/api/people/ages';
  const response = await fetch(url);
  const data = await response.json();
  allData.push(...data.data);
  cursor = data.cursor;
} while (cursor !== null);
